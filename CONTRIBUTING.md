# Contributing

Thanks for your interest in the Starship orbit visualizer!

## Ideas and bug reports

Please use [GitHub Issues](https://github.com/sanitaravel/starship-orbit-visualizer/issues/new/choose):

- **Bug report** – something is wrong or broken. Include the inputs you used and, if possible, a screenshot or console output.
- **Feature idea** – something you'd like the visualizer to do.

Please search existing issues first to avoid duplicates.

## Code changes

The code is maintained by the repository owner, who implements accepted ideas and fixes.
Direct pushes are restricted, and every change to `main` requires the owner's approval.
If you'd like to propose code, open an issue first to discuss it.
