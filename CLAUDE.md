# starship_trajectories

## Workflow

For any non-trivial task:
1. **Plan** (you): break the task into steps. Use plan mode for big changes.
2. **Docs**: if a step uses an external library, delegate to `docs-researcher` first.
3. **Code**: delegate each step to `coder`, passing the plan step + docs brief.
4. **Review**: delegate to `reviewer`. If it finds issues, send them back to `coder`.
5. **Document**: after review passes, delegate to `docs-writer` to update the README and docstrings.
6. Report the final summary to me.
